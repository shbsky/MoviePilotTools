# 鸿蒙版小范围测试（AppTest 邀请测试）操作手册

> 目标：不上架应用市场，只把鸿蒙版发给一小撮人试用，收集反馈。
> 结论先给：**走 AGC 的「应用测试 → 邀请测试（AppTest）」**，这是唯一一条不用公开上架、又不用对方自己编译的路。
> 但有个绕不开的前提：**必须换成「发布证书 + 发布 Profile」**，调试证书（DevEco 自动生成那个）只能装机调试，提交测试会被拒。

---

## 0. 三条渠道怎么选

| 渠道 | 包发在哪 | 谁能装 | 人数上限 | 审核 | 适合 |
| --- | --- | --- | --- | --- | --- |
| **AppTest 邀请测试** | 独立的 AppTest 应用内 | 收到邀请的人（用 AppTest 客户端） | 内部 100 / 外部 10000 | 快，几十分钟到 1 天 | **你要的小范围测试** |
| AppGallery 邀请测试 | 应用市场「测试专区」 | 有邀请码的华为账号 | 10000 | 同邀请测试 | 有种子用户群，想看起来"在应用市场里" |
| 公开测试 | 应用市场 | 所有人 | 下载上限 1000 万 | 按上架标准审 | 上架前灰度 |

> API ≥ 10 的 HarmonyOS 应用**没有**「开放式测试」入口，别去找，那是 API ≤ 9 的老通道。

## 1. 前置准备（这几步最花时间，先做）

### 1.1 华为开发者账号实名认证

- 个人开发者可以：身份证 + 人脸认证，一般当天过。
- 企业开发者：营业执照，审核 1~3 个工作日。
- 地址：<https://developer.huawei.com/consumer/cn/> → 控制台 → 账号中心 → 实名认证。

### 1.2 在 AGC 创建应用

1. 进 **AppGallery Connect** → 「我的应用」→「创建应用」；
2. 平台选 **HarmonyOS**（不是 Android）；
3. **包名必须填 `com.moviepilottools.mptools`**，跟你 `AppScope/app.json5` 里的 `bundleName` 一字不差，写错了后面全部白做；
   - ⚠️ 包名**不能把保留字符当作独立段**：`oh` / `ohos` / `harmony` / `harmonyos` / `openharmony` / `system` 都算，会被拦并提示「应用包名中包含敏感词或者保留字符」。`com.xxx.harmony` 这种写法建不了应用（旧的 `com.moviepilottools.harmony` 就栽在这）；
4. 应用名称填 `MoviePilotTools`。

### 1.3 申请发布证书 + 发布 Profile（关键，别用调试证书）

这是最容易卡住的一步。DevEco Studio 里「Automatically generate signature」给的是**调试证书**，它的 Profile 只对登记过的设备 UDID 生效——提交测试包会直接被判不合法。

正确流程：

1. **生成密钥和证书请求文件（CSR）**
   DevEco Studio → `Build` → `Generate Key and CSR`，生成 `.p12`（密钥库，密码自己记牢）和 `.csr`。
2. **申请发布证书**
   HarmonyOS 开发者中心 →「证书、APP ID 和 Profile」→「证书」→「新建证书」→ 类型选 **发布证书** → 上传 `.csr` → 下载 `.cer`。
   - 每个账号最多 3 个发布证书。
3. **申请发布 Profile**
   同一页面 →「Profile」→「新建 Profile」→ 类型选 **发布** → 关联上面那张证书 → 绑定应用 `com.moviepilottools.mptools` → 下载 `.p7b`。
   - 一个应用最多 100 个 Profile。
4. **在工程里换签名**
   打开 `harmony-app/MoviePilotTools-Harmony/build-profile.json5`（这个文件不进仓库，模板见 `build-profile.example.json5`），把 `material` 换成：

   ```json5
   certpath:      '<发布证书>.cer 的路径',
   profile:       '<发布 Profile>.p7b 的路径',
   storeFile:     '<密钥库>.p12 的路径',
   storePassword: '<p12 密码>',
   keyAlias:      '<别名>',
   keyPassword:   '<密钥密码>',
   ```

   改完在 DevEco 里 `File → Project Structure → Signing Configs` 能看到这张证书，说明生效。

> 想保留现在能直接装机调试的那套，就别覆盖原文件——先备份 `build-profile.json5`，测完再换回来。

### 1.4 APP 备案（邀请测试不需要，可跳过）

官方邀请测试 FAQ 明确回答：**「发布邀请测试，应用需要先提供资质、备案吗？→ 不需要。」**

工信部 APP 备案只有**正式全网上架**才强制，AppTest / AppGallery 邀请测试都不用办。
唯一例外：AGC 提交页面当场要求填备案号时，以页面提示为准。

## 2. 打 Release 包（要 `.app`，不是 `.hap`）

测试发布上传的是 **`.app`**（应用包，里面可以含多个 HAP），不是单个 `.hap`。

- DevEco Studio：`Build` → `Build Hap(s)/APP(s)` → **`Build APP(s)`**；
- 产物：`build/outputs/default/` 下的 `xxx.app`；
- 必须是 **Release 模式** + **发布证书签名**，Debug 包一律不收。

DevEco Studio 5.0.5.200 以后还可以直接 `Build` → **`Upload Product`** 一步上传，上传时选：

- `Generate app package and upload it to AppGallery Connect for test`（只测试）
- 签名选 `Manually manage signing`（用你 1.3 做的那套）或 `Automatically manage signing`（用 AGC 云证书，会重新签名）

## 3. 建测试用户群组

**内部群组**（推荐你先用，人数少、审核最快）：

1. 登录 **HarmonyOS 开发者中心** →「应用管理」；
2. 左上角切到 `MoviePilotTools`；
3. 左侧导航 →「分发」→「应用测试/元服务测试」→「测试用户」；
4. 选「内部测试用户群组」→ 右上角「创建测试群组」→ 类型「内部」→ 填名称 → 创建；
5. 点该群组「操作 → 管理」→「添加测试用户」→ 勾选要邀请的人 → 添加。

**外部群组**（给非团队成员）：

同上路径，选「外部测试用户群组」→「创建测试群组」→ 添加测试用户。

- 华为账号必须是**邮箱格式**（短信邀请方式已停用）；
- 支持单个添加和批量导入，外部累计上限 10000；
- 内部群组里的人必须是「拥有该应用权限的 HarmonyOS 开发者中心用户」，加人前先到「开发者管理 → 用户与访问」给他开权限。

**注意**：往已在进行的测试里加人，系统**不会**自动补发邀请，要手动点「重新邀请」，或者把邀请链接/邀请码私发过去。

## 4. 创建测试版本

1. AGC →「我的应用」→ 选 `MoviePilotTools` →「分发」→「应用测试」→「创建测试版本」；
2. **选择软件包**：上传第 2 步的 `.app`，AGC 会解析 `pack.info` 显示包名、版本号、包含的 HAP 列表 —— 核对包名是 `com.moviepilottools.mptools`、版本号是 `1.0.0 (1)`；
3. **版本描述**：≤ 30 字，比如「v1.0.0 小范围测试」；
4. **测试信息**（不影响正式上架信息）：
   - 应用图标、应用名称；
   - 应用介绍（≤ 8000 字）；
   - **测试说明**（≤ 1000 字）——写清测什么、怎么反馈、你的联系方式；
5. **隐私声明**：自定义隐私政策网址，或用华为「隐私声明托管服务」生成（个人开发者建议用托管，省事）；
6. **联系方式**：中国大陆开发者必须填应用负责人联系方式，审核会联系你；
7. **上架自检**：
   - 选「是」→ 顺带按正式上架标准自检，约 1 天，能提前发现上架问题；
   - 选「否」→ 只提交邀请测试审核，快。
8. **下一步 → 选择测试用户**：勾选第 3 步建的群组（最多 30 个列表）；
9. 提交。

## 5. 测试怎么装到手机上

三种方式，任选：

| 方式 | 做法 |
| --- | --- |
| 邮件邀请 | 审核通过且测试时间生效后，系统自动发邮件给测试用户，点邮件里的链接 → 用 AppTest 客户端安装 |
| 邀请链接 / 邀请码 | 在测试版本详情页复制链接和邀请码，直接私发给对方；对方点链接登录华为账号 → 输入邀请码 → 安装 |
| AppTest 客户端 | 用户装「AppTest」App，登录后能在里面看到受邀的测试版本，直接安装、更新 |

用户侧只需要：**一个华为账号 + 装 AppTest 客户端**，不用开发者身份、不用自己编译。

## 6. 容易踩的坑

| 坑 | 表现 | 解法 |
| --- | --- | --- |
| 用了调试证书 | 提交时报签名不合法 / 提示 Profile 与证书不匹配 | 换 1.3 的发布证书 + 发布 Profile |
| 包名和 AGC 不一致 | 上传后提示应用不存在或无权限 | `bundleName` 必须等于 AGC 里注册的包名 |
| 传了 `.hap` | 上传被拒 | 要 `.app`（Build APP(s) 产物） |
| Debug 模式打包 | 上传被拒 | 必须 Release 构建 |
| 加人后没收到邮件 | 新成员没通知 | 手动「重新邀请」，或私发邀请链接 |
| 测试时间没到 | 搜不到、装不了 | 把开始时间设在提交后，别设成过去 |
| 以为要备案 | 白等好几天 | 邀请测试不需要备案，只有正式上架才要 |
| 包名带保留字 | 建应用时报「包含敏感词或者保留字符」 | 别用 `harmony` / `ohos` 等作独立段 |
